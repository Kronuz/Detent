# Validated Architectural Blueprint

Date: 2026-10-28. **Conditional GO for implementation; acceptance remains open.** Reviewed working-tree `generation_file_access.hh:32-114`, `config_trust_internal.hh`, `generation_mapping.hh`, and `test_trusted_paths.cc`. No builds, tests, or measurements run.

1. **Evidence and decision.** The [40-process diagnostic](attach-diagnostic/result.json) reports private/shared median directory-trust caller CPU of 212.695/215.418 µs, versus attachment totals of 389.689/397.495 µs. It identifies a target, without measuring removable cost. In `generation_file_access.hh:69-95`, preliminary `entry` only classifies ordinary directories; its identity is never compared with the opened descriptor. Retaining the checks at lines 100-106 preserves the directory identity invariant.

2. **Mechanism and error handling.** Open each ordinary component first with exactly `O_RDONLY | O_DIRECTORY | O_CLOEXEC | O_NOFOLLOW`. On success, execute the existing held-descriptor type, owner, mode, ACL, and named-device/inode checks. On failure, save `errno` immediately. `ENOENT` remains `GenerationUnavailable`. Only `ELOOP`, `ENOTDIR`, and FreeBSD `EMLINK` qualify for a no-follow `fstatat` classification; FreeBSD explicitly documents [EMLINK for O_NOFOLLOW](https://man.freebsd.org/cgi/man.cgi?query=open&sektion=2). Missing classification remains unavailable; other inspection failures reject. A confirmed symlink enters the existing resolver unchanged. A non-symlink rejects without reopening or retrying. All other open errors reject directly. The later named check and alias after-check retain their existing trust-error classification, including disappearance.

3. **Security & Scale Review: invariants.** Keep the trusted root anchor, per-component held checks, final publisher ownership, and every alias check. Aliases require root ownership of both link and parent, a bounded readlink, and matching before/after device, inode, owner, and mode. An unrelated user cannot supply a traversable replacement without satisfying those checks. The existing policy trusts root and publisher ownership; preliminary stat adds no protection against their subsequent mutation. No flag relaxation or trust-result caching is permitted.

4. **Scalability Check and limits.** The change removes one metadata syscall per successfully opened ordinary component and adds one failed open per alias. Existing limits remain 256 processed components, 256 queued components, 40 links, and a 4097-byte readlink buffer. Descriptor retention stays proportional to traversal depth; no lookup-count or corpus-size state appears. Alias-heavy paths can regress. ACL cost remains, and directory-trust timing cannot predict the total first-read saving.

5. **Edge-Case Analysis and required tests.** Preserve empty/NUL rejection, relative paths, empty/dot components, dotdot at root, absolute-alias reset, relative-alias expansion, and exception unwinding. Run existing trust fixtures on supported macOS, Linux, and FreeBSD configurations. Add exact exception checks for missing components and dangling aliases; reject regular files, permission errors, and injected resource/I/O/interruption errors without entering the resolver. Exercise both symlink error variants plus FreeBSD `EMLINK`, alias ownership and replacement races, and 40/41-link and component-limit boundaries. Check returned descriptor identity/CLOEXEC and descriptor counts after failures. Replace the race hook's second-stat assumption (`test_trusted_paths.cc:23`) with injection explicitly after successful open and before named validation; assert the hook fires and the replacement is rejected. Ordinary traversal must perform only its retained named stat.

6. **Dependency & State Audit.** Keep one traversal implementation and the existing `RecoveryFile` ownership transfers. All error exits unwind through RAII. No new clock, runtime cache, shared-library change, or resource-adoption change belongs in this component.

7. **Bounded diagnostic and acceptance.** After correctness passes, run one counterbalanced four-arm diagnostic: private/shared × current/proposed traversal, the same 20 recorded keys, 80 fresh measured processes, matching warmups, fixed generation, compiler settings, and existing instrumentation. Record binary/source identities and identical lookup results under an exclusive host hold. Compare paired directory, attachment, and total first-read CPU/wall deltas separately in both resource arms. Require consistent end-to-end benefit without an arm regression; an isolated syscall-count win is insufficient. Only then run existing uninstrumented acceptance, including the unchanged sub-ms first-read gate. Otherwise discard this optimization. Review the complete component once.
