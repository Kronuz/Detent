## Managed process fixture

`tests/detent_delivery/test_managed_process.sh` binds port 0 in a child interpreter, closes the socket and passes the number on (`test_managed_process.sh:66` before the change). The approach of `742ffcd` (the poll fixture) is a kernel-selected port plus a retry on the bind collision. The shell fixture already selects by kernel; the missing half is the retry, which the change adds as a wrapper: a failed attempt whose log holds `bind: Address already in use` reruns the fixture with fresh ports, three attempts at most.

Injection: an interpreter shim (`.scratch/holdpy.sh`) leaves the first selected port held by a listener. With it, `test_relay_paged_isolated_process`'s arguments:

1. Old script: exit 1, `detentd: bind: Address already in use`.
2. New script: first attempt shows the same error, `Retrying managed fixture with fresh ports after a bind collision`, second attempt passes.
3. New script with the retry pattern mismatched (mutant): exit 1.
4. `ctest -R 'test_relay_paged_isolated_process|test_managed_delivery_process'` with the real interpreter: 3 of 3 pass.
